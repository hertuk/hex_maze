# 🔷 Hexagonal Maze Generator — лабиринты в шестиугольной сетке

> «Шесть сторон — шесть путей для исследования»

**Hexagonal Maze Generator** — это набор консольных утилит для генерации лабиринтов на шестиугольной сетке.  
Программа создаёт идеальные лабиринты с ячейками в форме шестиугольников, используя различные алгоритмы.

## 🚀 Особенности
- 🧠 Поддержка алгоритмов: **DFS** (по умолчанию), **Prim**, **Kruskal**, **Wilson**.
- 🔷 Настройка параметров: ширина (width) и высота (height) в шестиугольных координатах.
- 🎨 Визуализация в терминале с использованием ASCII-символов (шестиугольная сетка).
- 💾 Экспорт в JSON (структура данных) и SVG (векторная графика).
- 🧩 Решение лабиринта (поиск пути между двумя точками).
- ⚡ Настройка seed для воспроизводимости.
- 🌀 Шестиугольная структура: каждая ячейка имеет 6 соседей.

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости.

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | стандартная библиотека               | `python hex_maze.py`                    |
| Go         | стандартная библиотека               | `go run hex_maze.go`                    |
| JavaScript | Node.js, `fs` (стандартные)          | `node hex_maze.js`                      |
| Java       | стандартная библиотека               | `javac hex_maze.java && java hex_maze`  |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | `rand`, `serde`, `serde_json`        | `cargo run`                             |
| Ruby       | стандартная библиотека               | `ruby hex_maze.rb`                      |
| PHP        | стандартная библиотека               | `php hex_maze.php`                      |
